# Step 2: Get the course repository

## Option A (recommended): clone with RStudio

1. In RStudio: **File → New Project → Version Control → Git**.
2. Repository URL: `https://github.com/LisaLechner/network_science_ir.git`
3. Choose a folder on your laptop (not inside a cloud-synced folder like iCloud or OneDrive if you can avoid it) and click **Create Project**.

RStudio downloads all materials and opens the project. You now have a **Git** tab (top right). Before every session, click **Pull** there to get the newest materials.

## Option B: download as ZIP

On the GitHub page, click the green **Code** button → **Download ZIP**, unzip it, and double-click `network_science_ir.Rproj`. You will need to re-download for updates, so Option A is better.

## Fallback: Posit Cloud (no installation)

If your laptop setup fails, create a free account at <https://posit.cloud>, then **New Project → New Project from Git Repository** and paste the URL above. Everything runs in your browser.
